# Tummi (Personal Edition)

A free, offline-first, cross-platform mobile app (iOS & Android) for starting solids, baby-led weaning (BLW), purées, allergen tracking, meal planning, and feeding logs — inspired by [tummiapp.com](https://tummiapp.com) with zero subscriptions or paywalls.

## Features

- **First Foods Library**: Age-by-age prep (`6-8m`, `9-11m`, `12m+`) for both BLW finger foods and purées, cut sizes, textures, choking risk badges, and pairings.
- **100 Foods Before 1 Tracker**: Visual progress tracker + Food Passport with exposure counts.
- **Top 9 Allergens Tracker**: Tracks Peanut, Egg, Dairy, Wheat, Soy, Fish, Tree Nuts, Sesame, and Shellfish with safe intro tips and reaction history.
- **Food & Reaction Log + Pediatrician Export**: Log meals, acceptance, and reaction severity/symptoms; export a clean summary via native Share.
- **Weekly Meal Planner & Recipes**: Auto-generated 7-day plan with 1-tap meal swaps and baby-friendly recipes.
- **Meal Check**: Pick a plate photo and verify choking safety, cut size, and texture for your baby's current stage, with 1-tap logging.
- **Ask Tummi Feeding Assistant**: Works 100% free offline using your baby's profile and food log, with optional personal Gemini or OpenAI API key support.
- **Parent Tools**: AAP 6-question Readiness Quiz, Calorie Estimator (`80–120 kcal/kg/day`), and Gagging vs. Choking quick-reference modal.
- **Multi-Baby & Prematurity Support**: Switch between baby profiles and optionally adjust age for prematurity.

## Run on iPhone & Android

```bash
npm install
npx expo start
```

Scan the QR code with **Expo Go** on iPhone (Camera app) or Android (Expo Go app).
